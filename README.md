# 🎮 Python Games Collection

A collection of beginner-friendly Python console games developed to practice programming fundamentals and problem-solving using Python.

---

## 📌 Games Included

### 🎯 Guess the Number
- Guess a randomly generated number.
- Provides higher/lower hints.
- Limited number of attempts.

### 🔤 Hangman
- Guess the hidden word one letter at a time.
- Includes hints for each word.
- Input validation and play again option.

### ✂️ Rock Paper Scissors
- Play against the computer.
- Computer makes random choices.
- Displays the winner after every round.

### ⭕ Tic Tac Toe
- Play against the computer.
- Computer blocks winning moves and tries to win.
- Detects wins and draws.

## 🚀 How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run any game using:

```bash
python filename.py
```

Example:

```bash
python hangman_game.py
```
